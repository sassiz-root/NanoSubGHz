## اولین روشن‌شدن

هنگامی که برای اولین بار دستگاه را روشن می‌کنید (از طریق USB یا پین 5V)،
دنباله زیر اجرا می‌شود:

1. **صفحه Splash** (~۲ ثانیه):
   ```
   NanoSubGhz
   by Sassiz.Root
   ```

2. **پیام بوت** (~۱.۲ ثانیه):
   ```
   Booting...
   ```

3. **منوی اصلی** ظاهر می‌شود. اگر کارت SD نتواند مقداردهی اولیه شود،
   پیام `SD Init Fail` نمایش داده می‌شود — برق را قطع کنید، سیم‌کشی
   را بررسی کنید، کارت SD را دوباره جا بزنید و امتحان کنید.

> 💡 دستگاه **به کامپیوتر نیاز ندارد**. بعد از فلش شدن، مستقل کار می‌کند.

## پیمایش با دکمه‌ها

| دکمه | پین نانو | نقش معمول |
|---|---|---|
| **UP** | D8 | حرکت به بالا / افزایش |
| **DOWN** | D9 | حرکت به پایین / کاهش |
| **SELECT** | A0 | تأیید / ورود / اجرا |
| **BACK** | A1 | انصراف / حذف / بازگشت |
| **LEFT** | D6 | خروج به منوی اصلی |

### قوانین عمومی
- **LEFT** همیشه به **صفحه قبلی** برمی‌گردد.
- **SELECT** گزینه انتخاب‌شده را تأیید می‌کند.
- **BACK** بدون ذخیره لغو می‌کند (به‌جز در نمای جزئیات، که **کد
  انتخاب‌شده را حذف می‌کند** — به هشدار زیر توجه کنید).

> ⚠️ **هشدار:** در نمای *جزئیات کد*، **BACK کد را حذف می‌کند**. اگر
> فقط می‌خواهید خارج شوید، **LEFT** را بزنید.

## ۱. Sniff

**هدف:** دریافت کدهای ASK/OOK ورودی روی فرکانس انتخاب‌شده و ذخیره
آن‌ها روی کارت SD.

### مراحل

1. منو → **1.Sniff** → **SELECT**
2. انتخاب فرکانس:
   ```
   Sniff Frequency
   >433   315
   ```
   با **UP / DOWN** جابه‌جا شوید، **SELECT** برای تأیید و **LEFT**
   برای انصراف.
3. دستگاه وارد حالت شنود می‌شود:
   ```
   Sniff 433 MHz
   L=Exit
   ```
4. وقتی کدی دریافت شود، یک **اعلان کوتاه** (~۰.۶ ثانیه) ظاهر می‌شود:
   ```
   433MHz RSSI:4
   C:A1B2C3
   ```
   کد **قبل از بازگشت صفحه به حالت شنود، به‌طور خودکار ذخیره می‌شود**.
5. برای خروج **LEFT** را بزنید.

### چه اطلاعاتی ذخیره می‌شود

- کد دریافت‌شده (هگز)
- شماره پروتکل (۱ تا ۱۲، طبق RCSwitch)
- طول بیت (معمولاً ۱۲ / ۲۴ / ۳۲)
- RSSI تخمینی (۰ تا ۵، نیازمند پین AGC روی RXB6)
- مدولاسیون: `ASK` (ثابت)

### نکات
- هر دریافت یک نوشتن روی SD (~۵ تا ۲۰ میلی‌ثانیه) مصرف می‌کند — در
  این بازه، کدهای جدید دریافت نمی‌شوند.
- **برد بستگی به آنتن دارد.** بدون آنتن: چند سانتی‌متر. با سیم ۱۷.۳
  سانتی: ۱۰ تا ۳۰ متر.
- **بررسی حداقل سیگنال وجود ندارد** — نویز ممکن است در CSV ظاهر شود.
  خطوط نویزی واضح را از *View Code* حذف کنید.

## ۲. View Code

**هدف:** مرور، بررسی، بازپخش یا حذف کدهای ذخیره‌شده.

### مراحل

1. منو → **2.View Code** → **SELECT**
2. انتخاب فرکانس (۴۳۳ / ۳۱۵) — همان رابط Sniff.
3. نمای فهرست باز می‌شود:
   ```
   433MHz 1/14
   Sel Info L=Back
   ```
4. با **UP / DOWN** کد انتخاب‌شده را تغییر دهید.
5. **SELECT** را بزنید تا نمای **جزئیات** باز شود:
   ```
   C:A1B2C3
   P1 B24 R4 ASK
   ```
   *(کد / پروتکل / بیت / RSSI / مدولاسیون)*
6. در نمای جزئیات:
   | دکمه | عملکرد |
   |---|---|
   | **SELECT** | بازپخش این کد |
   | **BACK** | **حذف** این کد ⚠️ |
   | **LEFT** | بازگشت به فهرست |
7. از نمای فهرست:
   - **LEFT** یا **BACK** → بازگشت به منوی اصلی

### نکات بازپخش
- بازپخش، کد را یک‌بار با ماژول فرستنده متناظر ارسال می‌کند.
- باید `Sent!` روی LCD ببینید.
- اگر دستگاه هدف **پاسخ نمی‌دهد**، احتمالاً پروتکل، طول بیت یا زمان‌بندی
  پالس با نسخه اصلی متفاوت است (رایج در کدهای Rolling).

### صفحه‌بندی
- هر کد در یک صفحه (بسته‌بندی نشده)، چون جزئیات هر ورودی ۱۶ کاراکتر
  عرض دارد.
- نشانگر موقعیت به‌صورت `جاری/کل` نمایش داده می‌شود.

## ۳. Jam

**هدف:** ارسال نویز OOK پیوسته همزمان روی **هر دو** فرکانس ۳۱۵ و ۴۳۳
مگاهرتز.

### مراحل

1. منو → **3.Jam** → **SELECT**
2. صفحه هشدار برای ۱.۵ ثانیه ظاهر می‌شود:
   ```
   Jamming 433+315
   L=Stop
   ```
3. بک‌لایت LCD خاموش می‌شود (صرفه‌جویی انرژی)، سپس Jam شروع می‌شود.
4. برای توقف **LEFT** را بزنید.

### ⚠️ ایمنی
- **خارج از محفظه Faraday استفاده نکنید** مگر اینکه مالک همه چیز در
  اطراف باشید.
- Jam ممکن است باعث **تداخل دائمی** با دستگاه‌های اضطراری شود — این
  می‌تواند جرم کیفری باشد.
- دستگاه تا زمانی که **LEFT** را نزنید یا برق قطع نشود، ارسال می‌کند.
- فرستنده ممکن است در طول Jam طولانی **گرم** شود. تست‌ها را کوتاه
  نگه دارید.

### چه کار می‌کند
- هر دو پین فرستنده را با نرخ ~۱۰ کیلوهرتز به‌سرعت سوئیچ می‌کند.
- این کار باند را اشغال کرده و گیرنده‌های مجاور را از رمزگشایی سیگنال
  مشروع بازمی‌دارد.

## ۴. Brute-Force

**هدف:** پیمایش تمام کدهای ممکن برای یک طول بیت مشخص و ارسال هر یک.

### مراحل

1. منو → **4.Brute-Force** → **SELECT**
2. انتخاب فرکانس (۴۳۳ / ۳۱۵)
3. انتخاب طول بیت:
   ```
   Brute Bit Length
   >12b  16b(~30m)
   ```
   | بیت | تعداد کد | زمان تخمینی |
   |---|---|---|
   | ۱۲ | ۴,۰۹۶ | ~۱۰ ثانیه |
   | ۱۶ | ۶۵,۵۳۶ | ~۳۰ دقیقه |
4. برای شروع **SELECT** را بزنید.
   ```
   Brute 433MHz 12b
   L=Stop
   ```
5. پیشرفت هر ۳۲ کد به‌روزرسانی می‌شود.
6. هر زمان بخواهید با **LEFT** متوقف کنید.

### ⚠️ هشدار قانونی
Brute-Force فقط روی **دستگاه خودتان** قانونی است. تلاش برای Brute-Force
روی دستگاه شخص دیگر جرم کیفری است.

### عملکرد
- ~۴۰۰ کد در ثانیه (محدود به `RCSwitch::send()` در پروتکل ۱)
- دستگاه **نمی‌تواند موفقیت را تشخیص دهد** — باید هدف را ببینید
  (مثلاً آیا درب باز شد؟).
- برای کرک واقعی، به SDR و تحلیل پروتکل مناسب نیاز دارید
  (به **Universal Radio Hacker** مراجعه کنید).

## ۵. Clear Data

**هدف:** پاک کردن کامل `codes_433.csv` و `codes_315.csv`.

### مراحل

1. منو → **5.Clear Data** → **SELECT**
2. پیام تأیید ظاهر می‌شود:
   ```
   Clear all?
   Sel=Y  Back=N
   ```
3. **SELECT** → فایل‌ها خالی می‌شوند. **BACK** یا **LEFT** → انصراف.

> این کار **هیچ فایل سفارشی دیگری** را که به کارت SD اضافه کرده‌اید
> حذف نمی‌کند.

## ۶. Shutdown

**هدف:** توقف ایمن تمام فعالیت‌ها قبل از جدا کردن دستگاه.

### مراحل

1. منو → **6.Shutdown** → **SELECT**
2. پیام ظاهر می‌شود:
   ```
   Shutting down
   ```
3. تمام گیرنده‌ها و فرستنده‌ها غیرفعال می‌شوند. کارت SD تخلیه و آزاد
   می‌شود.
4. پیام نهایی ظاهر می‌شود:
   ```
   Safe Unplug
   Power off now
   ```
5. بک‌لایت خاموش می‌شود. **اکنون می‌توانید برق را قطع کنید.**

> ⚠️ دستگاه **نمی‌تواند خودش برق خودش را قطع کند** — این پیام درخواستی
> از شما برای قطع برق است. برای راه‌اندازی مجدد، دکمه **RESET** را بزنید
> یا برق را قطع و وصل کنید.

> 💡 اگر می‌خواهید خاموشی سخت‌افزاری خودکار داشته باشید، یک **رله ۵ ولت**
> یا **P-MOSFET** را با یک پین آزاد (مثلاً A2) کنترل کنید تا برق اصلی
> قطع شود.

## فایل‌های SD

بعد از چند دریافت، کارت SD شامل موارد زیر خواهد بود:

```
/
├── codes_433.csv
└── codes_315.csv
```

### فرمت
جدا‌شده با کاما، یک خط برای هر دریافت:
```
<code_hex>,<protocol>,<bits>,<rssi>,<modulation>
```

مثال `codes_433.csv`:
```
A1B2C3,1,24,4,ASK
F0E1D2,2,12,3,ASK
0000FF,1,24,0,ASK
```

### باز کردن روی کامپیوتر
- **Linux / macOS:** با Numbers / LibreOffice / `column -t -s,` باز کنید
- **Windows:** به `.txt` تغییر نام دهید یا مستقیم با Excel باز کنید
  (کاما به‌عنوان جداکننده)
- اختیاری: تبدیل به JSON برای تحلیل بیشتر:
  ```bash
  awk -F, '{printf "{\"code\":\"%s\",\"proto\":%d,\"bits\":%d,\"rssi\":%d}\n",$1,$2,$3,$4}' codes_433.csv
  ```

## نکات و بهترین شیوه‌ها

### کیفیت دریافت
- **آنتن اضافه کنید.** ۱۷.۳ سانتی‌متر برای ۴۳۳ مگاهرتز، ۲۳.۸ سانتی‌متر
  برای ۳۱۵ مگاهرتز (λ/4).
- گیرنده‌ها را از کابل USB و کابل LCD (منابع نویز) دور نگه دارید.
- هنگام اولین یادگیری، دستگاه را **در فاصله ۱ تا ۵ متری** هدف نگه دارید.
- ریموت را **۳ تا ۵ بار** فشار دهید تا یک بسته کامل دریافت شود؛ RCSwitch
  اغلب فقط با تکرار دریافت می‌کند.

### ذخیره‌سازی
- هر چند صد دریافت، کارت SD را خالی کنید، وگرنه کدها انباشته می‌شوند.
- برای آرشیو، فایل CSV را از کارت SD کپی کرده و فایل را پاک کنید.

### توان
- **از پین 3.3V تغذیه نکنید** — رگولاتور داخلی نانو مناسب است، اما
  گیرنده‌های ASK به ولتاژ حساس‌اند. از USB یا منبع ۵ ولت تمیز استفاده کنید.
- اگر Jam طولانی انجام می‌دهید، روی ماژول‌های فرستنده **هیت‌سینک**
  اضافه کنید.

### بهداشت حقوقی
- یک **دفتر آزمایشگاه** با تاریخ، زمان و شواهد مالکیت دستگاه برای هر
  تست نگه دارید.
- تمام دریافت‌های مربوط به دستگاه‌های شخص ثالث را داخل یک **کیسه
  Faraday** انجام دهید.
- برای پژوهش، یافته‌ها را از طریق **افشای مسئولانه** ارسال کنید.

## عیب‌یابی

| علامت | علت احتمالی | رفع |
|---|---|---|
| `SD Init Fail` | سیم‌کشی، پین CS اشتباه، کارت خراب | D10 را بررسی کنید، FAT32 فرمت کنید، کارت کوچکتر امتحان کنید |
| LCD بلوک‌های خالی نشان می‌دهد | آدرس I2C اشتباه | `0x27` → `0x3F` در اسکچ تغییر دهید |
| هیچ کدی دریافت نمی‌شود | بدون آنتن، خیلی دور، باند اشتباه | آنتن نصب کنید، نزدیک‌تر شوید، فرکانس را بررسی کنید |
| همه دریافت‌ها `RSSI:0` | پین AGC روی RXB6 نیست | از RXB6 استفاده کنید یا فرمول `readRSSI()` را معکوس کنید |
| بازپخش کار نمی‌کند | پروتکل اشتباه، کد Rolling | مطمئن شوید هدف از کد ثابت استفاده می‌کند؛ دوباره دریافت کنید |
| Brute-Force قفل می‌کند | ارسال خیلی سریع | نرخ حلقه را کاهش دهید (`delayMicroseconds` اضافه کنید) |
| دستگاه تصادفی ری‌استارت می‌شود | Brown-out (USB ناکافی) | از منبع ۵ ولت اختصاصی استفاده کنید، خازن ۱۰۰ میکروفاراد اضافه کنید |
| داده‌های نامفهوم در CSV | نویز از باندهای مجاور | از فیلتر Band-pass استفاده کنید، شیلد محافظ اضافه کنید |
| `Read Err` در View | فایل SD خراب | کارت را فرمت کنید، در حین نوشتن کارت را بیرون نکشید |

### دیباگ سریال (اختیاری)
Serial به‌طور پیش‌فرض غیرفعال است تا **~۱۲۸ بایت SRAM** ذخیره شود.
برای فعال‌سازی:
1. در `setup()` مقدار `Serial.begin(115200);` را اضافه کنید
2. بلوک‌های `#define DEBUG` را از کامنت خارج کنید (به‌طور پیش‌فرض
   موجود نیست)
3. توجه: مقداری SRAM آزاد از دست می‌دهید

## سوالات متداول

**س: آیا می‌توانم همزمان ۳۱۵ و ۴۳۳ را شنود کنم؟**
ج: با این گیرنده‌ها شنود واقعاً همزمان ممکن نیست. فریمور فعلی در هر
جلسه یک باند انتخاب می‌کند. برای شنود واقعی دو باند، به **CC1101** ارتقا
دهید.

**س: چرا RSSI همیشه صفر نشان می‌دهد؟**
ج: اکثر ماژول‌های ASK ارزان (XY-MK-5V) پین AGC ندارند. فقط RXB6 و
گیرنده‌های سوپرهتروداین مشابه، پین AGC دارند.

**س: آیا می‌توانم ریموت خودرو را کلون کنم؟**
ج: **نه.** خودروهای مدرن از **کدهای Rolling** استفاده می‌کنند
(KeeLoq، HITAG و غیره). این دستگاه فقط پروتکل‌های OOK با **کد ثابت**
(PT2262، EV1527) را پشتیبانی می‌کند. به [protocols.md](protocols.md)
مراجعه کنید.

**س: چقدر می‌تواند ارسال کند؟**
ج: با آنتن تطبیق‌شده و خط دید باز، حدود ۱۰ تا ۳۰ متر در ۴۳۳ مگاهرتز.
دیوارها، فلز و سایر فرستنده‌ها این برد را به‌شدت کاهش می‌دهند.

**س: آیا این کار در کشور من قانونی است؟**
ج: **قوانین محلی خود را بررسی کنید.** شنود و Jam در اکثر کشورها
غیرقانونی است. به [DISCLAIMER.md](../DISCLAIMER.md) مراجعه کنید.
