> **ابزار Sub-GHz برای آردوینو نانو** — شنود، بازپخش و تحلیل سیگنال‌های ASK در باند ۳۱۵/۴۳۳ مگاهرتز

## 🧰 تجهیزات موردنیاز

| قطعه | تعداد | توضیح |
|---|---|---|
| آردوینو نانو (ATmega328P) | ۱ | نسخه ۱۶ مگاهرتز (کلون) هم مناسب است |
| LCD 1602 + پشت I2C | ۱ | آدرس I2C `0x27` (در صورت `0x3F` در کد تغییر دهید) |
| ماژول کارت SD | ۱ | SPI، FAT16/FAT32، حداکثر ۳۲ گیگابایت |
| کارت Micro SD | ۱ | فرمت‌شده FAT32 |
| گیرنده ASK 433 مگاهرتز | ۱ | مثلاً **RXB6** برای پشتیبانی از پین AGC |
| گیرنده ASK 315 مگاهرتز | ۱ | مثلاً **RXB6** برای پشتیبانی از پین AGC |
| فرستنده ASK 433 مگاهرتز | ۱ | مثلاً FS1000A |
| فرستنده ASK 315 مگاهرتز | ۱ | مثلاً FS1000A |
| دکمه فشاری | ۵ | LEFT, UP, DOWN, SELECT, BACK |
| آنتن | ۴ | سیم ۱۷.۳ سانتی برای ۴۳۳ و ۲۳.۸ سانتی برای ۳۱۵ |
| بردبورد و سیم جامپر | — | — |

> 💡 **توصیه:** به جای ماژول‌های ارزان **XY-MK-5V** از **RXB6** استفاده کنید.
> ماژول‌های RXB6 **پین AGC** دارند که قابلیت RSSI را فعال می‌کند و
> حساسیت و گزینش‌پذیری بسیار بهتری دارند.

## 💻 نصب نرم‌افزار

### ۱. نصب Arduino IDE
از [arduino.cc/en/software](https://www.arduino.cc/en/software) دانلود کنید.

### ۲. نصب کتابخانه‌های لازم
از مسیر **Sketch → Include Library → Manage Libraries** نصب کنید:

| کتابخانه | نویسنده | کاربرد |
|---|---|---|
| **RCSwitch** | sui77 | رمزگذاری/رمزگشایی OOK/ASK |
| **LiquidCrystal I2C** | Frank de Brabander | درایور LCD I2C |
| **SD** | Arduino / SparkFun | داخلی (بررسی نصب) |
| **SPI** | Arduino | داخلی |

### ۳. آپلود فریمور
1. فایل `firmware/NanoSubGHz.ino` را باز کنید
2. از **Tools → Board → Arduino Nano** انتخاب کنید
3. از **Tools → Processor → ATmega328P** (یا Old Bootloader در صورت نیاز)
4. پورت COM صحیح را انتخاب کنید
5. روی **Upload** کلیک کنید

### ۴. آماده‌سازی کارت SD
- با فرمت **FAT32** فرمت کنید
- فایلی لازم نیست — فریمور خودش در اولین بوت فایل‌ها را می‌سازد

## 🎮 نحوه استفاده

برای راهنمای کامل به [docs/usage.md](docs/usage.md) مراجعه کنید.

### شروع سریع

1. برق وصل کنید → صفحه Splash با عنوان `NanoSubGhz` / `by Sassiz.Root` → پیام `Booting...` → منو
2. با **UP / DOWN** حرکت کنید، با **SELECT** تأیید و با **LEFT** بازگردید
3. گزینه **Sniff** را بزنید → فرکانس (۴۳۳ یا ۳۱۵) را انتخاب کنید → SELECT → شنود شروع می‌شود
4. هر کد به‌طور خودکار در `/codes_433.csv` یا `/codes_315.csv` ذخیره می‌شود
5. برای خروج از Sniff دکمه **LEFT** را بزنید

### ساختار منو

```
┌─────────────────────────────┐
│ >1.Sniff                    │
│  2.View Code                │
│  3.Jam                      │
│  4.Brute-Force              │
│  5.Clear Data               │
│  6.Shutdown                 │
└─────────────────────────────┘
```

## 📂 فرمت فایل‌های SD

هر کد دریافت‌شده در یک خط CSV ذخیره می‌شود:

```
<code_hex>,<protocol>,<bits>,<rssi>,<modulation>
```

مثال:

```
A1B2C3,1,24,4,ASK
F0E1D2,2,12,3,ASK
```

| فیلد | معنا |
|---|---|
| `code_hex` | کد دریافت‌شده (هگزادسیمال) |
| `protocol` | شماره پروتکل RCSwitch (۱ تا ۱۲) |
| `bits` | طول بیت (معمولاً ۱۲، ۲۴ یا ۳۲) |
| `rssi` | قدرت تخمینی سیگنال (۰ تا ۵) |
| `modulation` | مقدار ثابت `ASK` برای این ماژول‌ها |

برای خروجی، کارت SD را جدا کرده و با هر برنامه صفحه‌گسترده باز کنید.

## 🐛 محدودیت‌های شناخته‌شده

- ماژول‌های **ASK ارزان (XY-MK-5V, FS1000A)** نویزی هستند. کیفیت دریافت
  بسیار پایین‌تر از SDR یا Flipper Zero است.
- **شنود واقعاً همزمان دو باند وجود ندارد** — فریمور برای ذخیره RAM و
  جلوگیری از تداخل، در هر لحظه فقط یک گیرنده را فعال می‌کند. اگر نیاز به
  شنود همزمان دو باند دارید، به **CC1101** ارتقا دهید.
- **RSSI نیازمند RXB6 است**. روی گیرنده‌های ارزان XY-MK-5V مقدار RSSI
  همیشه `0` خواهد بود.
- **فقط OOK/ASK** — سیگنال‌های FSK، GFSK و Manchester توسط این ماژول‌ها
  پشتیبانی نمی‌شوند.
